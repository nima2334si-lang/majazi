# ربات شماره مجازی – بازنویسی Python

## اجرا

1. Python 3.11 یا جدیدتر نصب کن.
2. وابستگی‌ها را نصب کن:
   `pip install -r requirements.txt`
3. `.env.example` را به `.env` تغییر نام بده و مقدارهای واقعی را وارد کن.
4. اجرا:
   `python bot.py`

## تنظیمات اصلی

| متغیر | کاربرد |
|---|---|
| `BOT_TOKEN` | توکن ربات اصلی از BotFather |
| `ADMIN_IDS` | شناسه عددی مدیرها؛ با کاما جدا شوند |
| `FIVESIM_API_KEY` | کلید پنل 5sim-compatible برای خرید شماره و دریافت پیامک |
| `ROUBLE_RATE` | ضریب تبدیل قیمت پنل به تومان؛ مقدار پایه سورس ۶۰۰ است |
| `CHANNEL` | کانال عضویت اجباری، بدون @؛ خالی باشد غیرفعال است |
| `REPORT_CHANNEL` | کانال گزارش فروش |
| `SUPPORT_USERNAME` | آیدی پشتیبانی، بدون @ |
| `INAX_USERNAME` / `INAX_PASSWORD` | دسترسی خرید شارژ مستقیم و کد شارژ سیم‌کارت |
| `SENATOR_API_KEY` | دسترسی خدمات ممبر تلگرام |
| `ZARINPAL_MERCHANT_ID` | مرچنت درگاه زرین‌پال |
| `PUBLIC_BASE_URL` | آدرس عمومی همین برنامه با HTTPS؛ برای برگشت پرداخت لازم است |
| `PORT` | پورت وب‌سرور؛ معمولاً توسط هاست تنظیم می‌شود |
| `DATABASE_PATH` | مسیر دیتابیس SQLite |

قیمت پایه ساخت ربات طلایی و نقره‌ای از `GOLD_BOT_PRICE` و `SILVER_BOT_PRICE` خوانده می‌شود و مدیر می‌تواند آن‌ها را از پنل تغییر بدهد. برای ساخت ربات نمایندگی، فروش نمایندگی‌ها باید از پنل مدیر فعال باشد.

## استقرار روی FadeHost

- Runtime: `Python`
- Install command: `pip install -r requirements.txt`
- Start command: `python bot.py`
- متغیرهای محیطی را در بخش Environment Variables وارد کن.
- فایل `.env` و دیتابیس را در مخزن عمومی GitHub قرار نده.
- دیتابیس `numberino.sqlite3` کنار فایل ربات ساخته می‌شود؛ برای حفظ موجودی و سفارش‌ها، هاست باید فضای ذخیره‌سازی ماندگار داشته باشد و از دیتابیس نسخه پشتیبان بگیر.
- برای پرداخت آنلاین، `PUBLIC_BASE_URL` باید آدرس HTTPS برنامه باشد و مسیر `/payment/callback/` از اینترنت در دسترس باشد.

## قابلیت‌های پیاده‌سازی‌شده

- منوی فارسی، عضویت اجباری، پروفایل، تاریخچه خرید و لینک زیرمجموعه‌گیری
- دریافت قیمت و موجودی سرویس/کشور از پنل، خرید شماره، دریافت خودکار پیامک، لغو و برگشت اعتبار
- کیف پول SQLite و پرداخت زرین‌پال با تأیید سمت سرور و جلوگیری از ثبت دوباره callback
- شارژ سیم‌کارت مستقیم یا دریافت PIN، نوع معمولی/شگفت‌انگیز و کارمزد ۹٪
- فهرست خدمات ممبر، ثبت سفارش، نمایش سفارش‌ها و بررسی دوره‌ای وضعیت/برگشت وجه
- ساخت ربات نمایندگی طلایی/نقره‌ای با توکن BotFather، اجرای ربات‌های فرزند و پنل مستقل؛ امکان ساخت زیرنمایندگی
- پنل مدیریت، آمار، توقف/فعال‌سازی فروش، تنظیم قیمت‌ها، ارسال همگانی، مدیریت موجودی کاربران، نمایندگی‌ها و درخواست تسویه
- API سازگار با الگوی سورس قدیمی در مسیر `/api.php`
- دیتابیس SQLite؛ نیاز به MySQL ندارد
- تاریخ و ساعت شمسی با منطقه زمانی تهران

بسته اینترنت در سورس PHP اصلی پیام «به‌زودی» داشت و در این بازنویسی هم فعال نشده است. اطلاعات اتصال و مرچنت‌های فایل PHP به‌صورت placeholder بودند؛ این نسخه هیچ کلید یا رمز واقعی را حدس نمی‌زند.

## API شماره مجازی

آدرس پایه: `https://YOUR-DOMAIN/api.php`

- موجودی: `?apikey=KEY&method=getBalance`
- خرید شماره: `?apikey=KEY&method=getNumber&country=usa&service=telegram&operator=any`
- وضعیت پیامک: `?apikey=KEY&method=getStatus&id=ACTIVATION_ID`
- تغییر وضعیت: `?apikey=KEY&method=setStatus&id=ACTIVATION_ID&status=-1`

مدیر از داخل ربات می‌تواند کلید بسازد و موجودی بدهد:
- `/createkey USER_ID AMOUNT`
- `/keyadd API_KEY AMOUNT`

## فرمان‌های مدیر

- `/panel` پنل مدیریت
- `/user USER_ID` اطلاعات کاربر
- `/add USER_ID AMOUNT` و `/sub USER_ID AMOUNT` تغییر موجودی
- `/ban USER_ID` و `/unban USER_ID`
- `/grantbot USER_ID gold` یا `/grantbot USER_ID silver` اعطای دسترسی ساخت ربات
- `/payouts` مشاهده درخواست‌های تسویه
- `/payapprove REQUEST_ID` تأیید درخواست تسویه (پرداخت بانکی باید جداگانه انجام شود)

## تست آفلاین

بعد از نصب وابستگی‌ها، در پوشه پروژه اجرا کن:
`python -m unittest discover -s tests -v`

تست‌ها دیتابیس، محاسبه قیمت، انتخاب اپراتور و مسیرهای پایه HTTP را بررسی می‌کنند. تست خرید واقعی، دریافت پیامک، شارژ و پرداخت به کلیدهای واقعی سرویس‌ها نیاز دارد.
